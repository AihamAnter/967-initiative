# خطة تطوير منصة 967

## فحص المشروع
- Next.js 15 App Router، React 19، JavaScript، npm، CSS، Lucide، Recharts، PDF.js.
- البيانات: Supabase مع RLS، نشر مستقل للأعمال والأعداد والأدلة والمؤشرات، ومصادقة ولوحة تحرير قائمة.
- المسارات الحالية محفوظة: الرئيسية، الأعمال وتفاصيلها، المجلة والقارئ، المرصد والمجالات والمؤشرات والمقارنة، الأطلس والشخصيات، الشركات والمهنيون وتفاصيلهم، الإدارة وواجهات API.
- الأصول المعتمدة: الشعار الشفاف الحالي وخريطة اليمن الحالية والحدود الجغرافية الموجودة.

## التنفيذ
1. توحيد الرموز البصرية والخط والشعار والتنقل المتجاوب والمكونات المشتركة.
2. بناء رئيسية تركز على الوصول والمحتوى المنشور، ثم المؤشرات والأطلس والأدلة والمبادرة والمشاركة.
3. اختصار مقدمات الأقسام، توحيد البحث والفلاتر والفراغ والترقيم وتحسين التفاصيل.
4. بحث عربي موحد في الحقول العامة فقط، ومسارات مساهمة تحفظ في نظام الرسائل الحالي.
5. إصلاح تحميل جميع قيم الإحصاءات واختيار أحدث قيمة صالحة، فصل العدادات وإخفاء التوثيق عن العينات.
6. اختبار lint والبيانات وBuild والمسارات والتجاوب على 360 و390 و768 و1024 و1440 بكسل.
