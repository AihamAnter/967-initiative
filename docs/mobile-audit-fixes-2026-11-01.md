# متابعة إصلاح مشكلات تجربة الهاتف — 1 نوفمبر 2026

## تغييرات تم تنفيذها
- **التذييل:** مجموعات الروابط على الكمبيوتر تُرسم كروابط عادية يمكن الوصول إليها بالكيبورد؛ على الهاتف تُعرض في `details` مستقلة ولا تظهر قبل فتحها.
- **لعبة الخريطة:** أُزيلت قائمة أسماء المحافظات التي كانت تكشف الإجابة؛ توجد أدوات تكبير حتى 350%، اختيار مباشر للمنطقة وإبرازها، ثم زر منفصل لتأكيد الموقع. لا تُحتسب اللمسة الأولى، ولا يظهر اسم المحافظة من الخريطة قبل التقييم.
- **الاختبار:** نقل التمرير عند بدء الجولة وكل سؤال إلى `useLayoutEffect` قبل الطلاء، مع تعطيل الحركة الناعمة لحظة النقل فقط، ومنع `scroll anchoring` على بطاقة اللعب وضغط المسافات في 320 و375 بكسل.
- **صفحة الألعاب:** التسع بطاقات أصبحت صفوفًا مختصرة على الشاشات الصغيرة مع العناوين والوصف والرابط محفوظة.
- **المدرسة:** بطاقة القسم القادم «الفنون والمهارات» لم تعد تفرض ارتفاع 245px في أضيق الشاشات.
- **الإحصاءات:** استثناء مقيد لمسار القياس المجمّع فقط يسمح بالأصل HTTPS نفسه خلف نفق تطوير محلي؛ لا تتغير قواعد الحماية في واجهات الإدارة. يجب إعادة قياس 403 على النفق الفعلي.
- **قاعدة البيانات:** أصبح ترحيل إصلاح نص الاستطلاع مسجّلًا في Supabase برقم `20261101010057`، وأعيدت تسمية ملف SQL في المستودع لمطابقة السجل. تحققنا من النص الفعلي للخيار.

## الفحص البصري المطلوب
الفحص السابق عبر Work بتاريخ 31 أكتوبر كان على النسخة *قبل* هذه الإصلاحات، لذلك لا يدل على نجاحها الآن. جرّب مجددًا:

1. `/games/quiz` بحجم 320×800 و375×800: جولة حرة 30 ثانية؛ بداية السؤال الأول، إجابة ثم «السؤال التالي». يجب أن يبقى السؤال والمؤقت داخل إطار الشاشة دون تمرير يدوي. كرر السؤال القصير والطويل.
2. `/games/map`: المنطقة مختارة أولًا ثم زر تأكيد؛ لا توجد قائمة بأسماء المحافظات. جرّب التكبير والتمرير ولمس محافظتين متجاورتين قبل التأكيد.
3. `/games`: جميع الألعاب التسع موجودة، بطاقات الهاتف أقصر من 260px. تحقق من النصوص والأزرار.
4. التذييل: عند 1440 تظهر روابط المدرسة والألعاب والمحتوى مباشرة، وعند 320 و375 تظهر مجموعات قابلة للفتح والإغلاق.
5. `/school`: «الفنون والمهارات» بطاقة قصيرة قرب آخر الصفحة، ولا تتجاوز الصفحة العرض الأفقي.
6. شبكة المتصفح: تأكد أن `POST /api/analytics/event` يُرجع `204`، سواء عبر `localhost:3000` أو عبر HTTPS Tunnel، ولا يرسل بيانات شخصية. يجب أن تظل طلبات Origin غير المطابقة مرفوضة `403`.

## اختبار Playwright اختياري

ملف: `tests/browser/mobile-967.spec.mjs`. لا يدخل في `npm test` ولا يحتاج إلى تغيير حزم الإنتاج.

بعد تشغيل `npm run dev` في جهازك:

```powershell
npm install --no-save --package-lock=false @playwright/test
npx playwright install chromium
$env:E2E_BASE_URL = 'http://localhost:3000'
npx playwright test tests/browser/mobile-967.spec.mjs --reporter=list
```

يشمل 320 و375 واختبار التذييل على الكمبيوتر. اختبار المتصفح هذا **لم يُشغَّل من بيئة هذه المحادثة** لعدم إمكانية الوصول إلى `localhost` الخاص بجهازك أو نفق Cloudflare من هنا. نجاح الفحوص البنيوية/البناء لا يغني عنه.
