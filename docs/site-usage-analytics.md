# تحليلات استخدام 967 — 31 أكتوبر 2026

## أين تظهر؟
- لوحة المحرر: `/admin/analytics`، برابط من قائمة الإدارة على الحاسوب والهاتف.
- مصدر البيانات الخاص بالإدارة: `GET /api/admin/analytics?days=7|30|90`؛ يتطلب جلسة Supabase Auth سليمة ودور `admin` أو `management` يؤكده الخادم في `editors`. لا يعيد سجلات المستخدمين.

## ماذا يقيس؟
1. إجمالي **مشاهدات** أقسام الموقع المسموحة، وليس عدد الزوار الفريدين.
2. الأقسام الأعلى مشاهدة خلال آخر 7/30/90 يومًا، وعدد مشاهدات كل يوم.
3. عدد عمليات البحث بلا نتائج موزعًا حسب تصنيف البحث فقط، دون نص البحث.
4. عدد الطلاب الذين حاولوا وأكملوا محطة في **عينة أحدث 3000 محاولة مصححة كحد أقصى**، مع نسبة الإكمال في العينة؛ تظهر المحطة عند 5 طلاب مختلفين على الأقل.
5. الأسئلة ذات الإجابات الخاطئة الأعلى في عينة المحاولات ذاتها، بعد 5 إجابات على الأقل للسؤال. لا يظهر بريد أو هوية الطالب أو إجاباته الفردية.

البيانات التعليمية **غير مرتبطة بفلتر أيام مشاهدات الموقع**. هذه العينة ليست تعدادًا لكل الطلاب ولا متوسطًا زمنيًا شاملاً.

## الخصوصية
- جدول `public.site_usage_daily` يحتفظ فقط بـ `day` و`metric` و`section` و`total`؛ التاريخ بتوقيت UTC. لا يسجل IP أو اسم مستخدم أو بريدًا أو كوكيز أو رابطًا تفصيليًا أو نص بحث أو User-Agent.
- لا تُرسل أحداث التتبع من صفحات الإدارة والحساب وتسجيل الدخول واستوديو المدرسة وبقية الصفحات الخاصة.
- إرسال أحداث الصفحات العامة اختياري من متصفح الزائر (تعطيله في `/privacy`) ويحترم `Do Not Track` و`Global Privacy Control`. الاختيار محلي على الجهاز، ولا يرتبط بمعرّف زائر.
- يمنع RLS/REVOKE وصول `anon` و`authenticated` للجدول والدالة؛ الزيادة الذرية عبر خادم Supabase service-role ودالة `SECURITY INVOKER` محددة الفئات، وليست إدخال بيانات خام.
- يجب عدم تفسير المشاهدات على أنها بشر فريدون؛ يمكن أن تتأثر بإيقاف التتبع أو زيارات آلية. الحد البسيط للطلبات في API لكل مثيل ليس حماية موزعة شاملة من التلاعب.

## التنفيذ والتحقق
- migration مطبقة في Supabase الحي: `20261031202332_site_usage_aggregate_analytics.sql`.
- تحققنا من منع SELECT/EXECUTE للدورين العامين، ومن صلاحية الخدمة، ومن الزيادة داخل معاملة ROLLBACK دون ترك سجلات اختبار.

- لا توجد أرقام تاريخية قبل بدء التتبع؛ تبقى اللوحة فارغة حتى يحدث استخدام فعلي.

## الحدود المقصودة
