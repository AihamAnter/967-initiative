# مصادر بحث دليلي الجامعات والمراكز الطبية

تاريخ الجمع والتحقق البرمجي: **2026-10-25**. لا تعني هذه الصفحة أن كل معلومة حديثة حتى هذا التاريخ؛ تاريخ كل سجل ومصدر محفوظ داخل ملف البيانات.

## المصادر المستخدمة

- [مجلس الاعتماد الأكاديمي وضمان جودة التعليم العالي](https://caqa.gov.ye/) — استُخدم دليل المؤسسات لإثبات هوية 53 مؤسسة تعليم عالٍ. الظهور في الدليل لا يُقدَّم في الموقع بصفته اعتمادًا للبرامج أو المؤسسة.
- [بوابة التنسيق لكليات المجتمع الحكومية](https://tanseek.net/gatecg.php) — الهوية والموقع ووسيلة الاتصال ومعلومة الإدراج للقبول، عند توفرها.
- [بوابة التنسيق للكليات الخاصة](https://www.tanseek.net/gatecs.php) — الهوية والموقع ووسيلة الاتصال ومعلومة الإدراج للقبول، عند توفرها.
- [Yemen Edu – دليل الجامعات](https://yemen-edu.com/universities) — مصدر مستقل مساعد للمطابقة الجغرافية ونوع الملكية، ولا يستبدل المصدر الرسمي.
- [وزارة الصحة العامة والسكان – القائمة الأساسية للمرافق الصحية](https://moh-ye.org/?page_id=7297) — هوية المنشأة، الكود الرسمي، النوع، المحافظة/المديرية، القطاع وحالة التشغيل المؤرخة في **ديسمبر 2023**.
- [WHO HeRAMS Yemen – Summary update report 2024-02](https://www.who.int/publications/m/item/herams-yemen-summary-update-report-2024-02) — سياق مستقل لحداثة المشهد الصحي، ولم يُستخدم لملء خدمات أو هواتف أو تخصصات أي منشأة.

## قابلية إعادة البناء

ينفّذ `scripts/prepare-institution-directories.mjs` التنظيف والمطابقة وإزالة التكرار وبناء ملفات JSON. لا تُحفظ نسخ HTML أو PDF الكبيرة في المستودع. لإعادة البناء، نزّل المصادر العامة بالأسماء التالية داخل `docs/research/`:

- `caqa-home.html`
- `tanseek-community-government.html`
- `tanseek-community-private.html`
- `yemen-edu-universities.html`
- `mophp-health-facilities-dec-2023.pdf` من رابط الوثيقة الذي توفره صفحة وزارة الصحة.

ثم شغّل:

```bash
node scripts/prepare-institution-directories.mjs
npm run data:directories -- --kind=all
```

الأمر الثاني محاكاة فقط؛ لا يفتح اتصالًا بقاعدة البيانات ولا يكتب أي سجل ما لم يُمرَّر `--apply` مع متغير التأكيد الصريح.

## سياسة عدم الاختلاق

- لا تُستنتج التخصصات أو الخدمات أو الرسوم أو أرقام الهواتف من اسم المنشأة أو نوعها.
- القيم غير الموجودة في المصدر تظل فارغة أو `null`.
- حالة تشغيل المنشآت الصحية تاريخية ومؤرخة، ولا تعرض الواجهة عبارة «مفتوح الآن».
- لم تُستخدم صور أو شعارات لم يتضح حق استخدامها؛ لذلك حقول الصور فارغة في مجموعة الاستيراد الحالية.
