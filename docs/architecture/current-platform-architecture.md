## الخدمات ومسؤولياتها

| الخدمة | الدور المعتمد |
| --- | --- |
| **Namecheap** | مسجل النطاق **967ye.com** وإدارة **DNS**؛ توجيه النطاق المخصص إلى Vercel. |
| **Vercel** | استضافة واجهة الموقع المبنية باستخدام **Next.js**؛ تقديم الصفحات والمنطق التطبيقي للمستخدم عبر HTTPS. |
| **GitHub** | مستودع الشفرة المصدرية لمشروع Next.js، ومنه تُدفع التغييرات للنشر. |
| **GitHub Actions** | تشغيل أتمتة المشروع، بما فيها عمليات النشر/سير العمل الآلي والنسخ الاحتياطية اليومية. |
| **Supabase PostgreSQL** | قاعدة بيانات التطبيق: المحتوى والبيانات والنقاط والتقدم والتعليقات وغيرها. |
| **Supabase Auth** | تسجيل الدخول وإنشاء الحسابات والجلسات وإعادة تعيين كلمة المرور. |
| **Supabase Storage** | تخزين الصور والصور الرمزية والملفات الإعلامية. |
| **Resend SMTP** | إرسال رسائل التحقق من البريد الإلكتروني وإعادة تعيين كلمة المرور، بعنوان الإرسال **no-reply@967ye.com**. |
| **Backblaze B2** | تخزين أرشيفات النسخ الاحتياطي المشفرة، مع سياسة احتفاظ **30 يومًا** حسب المخطط. |

## مسار الطلبات الرئيسية

1. يدخل المستخدم من الكمبيوتر أو الهاتف إلى `https://967ye.com`.
2. DNS المدار لدى Namecheap يوجه نطاق الموقع إلى Vercel.
3. Vercel يقدم تطبيق Next.js والواجهة والمنطق التطبيقي.
4. يحتاج التطبيق إلى Supabase للوصول إلى البيانات، والمصادقة، وتخزين الملفات.
5. يستخدم تدفق رسائل المصادقة إعداد Resend SMTP للرسائل المرتبطة بالتحقق وإعادة تعيين كلمات المرور.

## سير العمل والنشر

- **تعديل الشفرة ← GitHub ← نشر تلقائي إلى Vercel** حسب تكامل المستودع مع الاستضافة.
- **GitHub Actions** يقوم بسير العمل الآلي، بما في ذلك النسخ الاحتياطية اليومية المرسومة في المخطط.

## النسخ الاحتياطية

- نسخة **يومية** من قاعدة بيانات Supabase PostgreSQL.
- نسخة **يومية** من ملفات Supabase Storage.
- تُجهّز الأرشيفات **مشفرة** ثم تُرسل إلى **Backblaze B2**.
- مدة الاحتفاظ بحسب المخطط: **30 يومًا**.
- رسم المخطط يوضح **المسار المقصود**. سلامة الاستعادة الفعلية، وجدولة عمليات النسخ، والتنبيهات، وإدارة مفاتيح التشفير، وصلاحيات الوصول، تحتاج إلى مراجعة إعدادات GitHub Actions وBackblaze إن طُلب التحقق.

## اعتبارات التطوير المستقبلية

- قبل اقتراح تغيير الاستضافة أو قاعدة البيانات أو خدمة البريد أو التخزين، **ابدأ من هذه البنية** ولا تفترض بيئة تشغيل مختلفة.
- الموقع المباشر `967ye.com` يختلف عن النسخة المحلية على `localhost:3000` أو أي رابط اختبار قديم.
- حافظ على تكامل Supabase (Database/Auth/Storage) وResend SMTP والنسخ اليومية المشفرة عند تنفيذ تغييرات تتعلق بهذه المسارات.
- لا تُخزن في هذه الوثيقة كلمات مرور، أو مفاتيح `service_role`، أو بيانات SMTP السرية، أو مفاتيح تشفير النسخ الاحتياطية.
- عند أي تحديث لاحق من صاحب المشروع، عدّل هذه الوثيقة بتاريخ واضح بدل افتراض بقاء جميع التفاصيل دون تغيير.
