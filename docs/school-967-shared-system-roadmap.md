# مدرسة 967 — خطة النظام التعليمي المشترك

## قرار المنتج
استبعاد شهادات الإتمام من النظام كله؛ لا إنشاء أو عرض أو التحقق من شهادات.

## مراحل التنفيذ الخمس
1. **المحرك المشترك ولوحة الطالب (مكتملة):** فهرس موحد للمسارات، قراءة تقدم المسند والعروض من محاولات Supabase الحالية، توصية بالمحطة التالية، بيانات خاصة بالطالب، تصميم متجاوب دون ترحيل بيانات.
2. **XP ومستويات الطالب (المرحلة الثانية):** 100 نقطة XP لكل أول نجاح موثق في محطة، وسجل أحداث خاص متصل بتحديث نتيجة المحاولة داخل معاملة قاعدة البيانات نفسها؛ قيد فريد يمنع تكرار النقاط؛ ترحيل النجاحات القديمة؛ مستوى تراكمي بتكلفة تصاعدية. لا تُمنح نقاط إضافية للمحاولات المعادة.
3. **المراجعات والاستمرارية والأهداف:** مراجعة المهارات الخاطئة بعد التصحيح، أيام نشاط متتالية، أهداف يومية اختيارية، وحفظ إجابات السؤال الجاري دون كشف الإجابة الصحيحة.
4. **الإنجازات والمنافسة الاختيارية:** شارات معتمدة على إنجازات موثقة، لوحة صدارة أسبوعية وشهرية باشتراك اختياري وخصوصية مناسبة، ومقاومة التلاعب بالنقاط.
5. **نظام الإدارة والتأليف:** محرر مسارات ومحطات، بنك أسئلة مع مسودات ونشر وإصدارات، تحليلات الصعوبة وسجلات تعديل المحتوى.

## قواعد ثابتة
- لا شهادات إتمام في أي مرحلة.
- المسندان والعروض الموجودان لا تُعاد تهيئتهما ولا تُمسح نتائجهما.
- معاينة الإدارة لا تُنسب خطأ إلى إنجاز الطالب.
- XP والمؤشرات غير المنفذة لا تُعرض على أنها حقيقة.
- بيانات المستخدم الخاصة لا تُتاح عبر واجهات عامة أو بدون مصادقة.
