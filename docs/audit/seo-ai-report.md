# تقرير SEO وإتاحة المحتوى لأنظمة البحث بالذكاء الاصطناعي

التاريخ: 16 أكتوبر 2026. المسؤول: Search & AI Visibility Specialist، وكيل مستقل ضمن فريق المراجعة. الفرع: `audit/launch-readiness`. التعديلات محلية؛ لم يُنشر الموقع ولم تُعدّل سجلات الإنتاج.

## النطاق والأدلة

شملت المراجعة جميع ملفات `app/**/page.jsx`، والتخطيط العام، وطبقة البيانات للقراءة فقط، وملفات الزحف، والبيانات المنظمة، والظهور في HTML، ووثائق مزودي البحث الرسمية. لا تتضمن النتيجة ادعاء بأن Google أو Bing أو ChatGPT أو Perplexity فهرسوا الموقع أو استشهدوا به فعلياً.

توضح لقطة البداية `evidence/browser-before.json` أن الصفحات اختبرت محلياً بعناوين Canonical من `http://localhost:3000` مع السماح بالفهرسة. كانت اللغة العربية وRTL وعناوين H1 الأساسية موجودة. لذلك لم تُعَد كتابة المحتوى العربي لمجرد تكرار كلمات بحث.

الفحص المباشر للنسخة المنشورة وقياسات المقارنة ينفذهما مدير الفريق ويُرفقان في التقرير الموحد. لا تثبت نتيجة محلية أن النشر الحالي يتضمن الإصلاحات. لا توجد صلاحية متصلة إلى Search Console أو Bing Webmaster Tools أو سجلات برامج الزحف.

## سياسة الزحف والذكاء الاصطناعي

في الإنتاج يسمح `robots.txt` بالصفحات العامة مع استبعاد `/admin` و`/api/`. المجموعات المخصصة للبحث تكرر الاستثناءات الخاصة لأن المجموعة الأكثر تحديداً لا ترث مجموعة `*`. صفحات البحث والنماذج تبقى قابلة للوصول إلى noindex؛ ملفات التجربة لها ترويسة مستقلة.

| الخدمة/الوكيل | الغرض بحسب الوثائق الرسمية | القرار المنفذ |
|---|---|---|
| Googlebot | البحث التقليدي وميزات Google المعتمدة على البحث، ومنها AI Overviews/AI Mode | يبقى مسموحاً للمحتوى العام بواسطة القاعدة العامة؛ لا حيل خاصة |
| Google-Extended | تحكم مستقل في بعض التدريب والاستخدامات المرتبطة بـGemini، ولا يتحكم في فهرسة Google Search | لم نغير سياسة التدريب القائمة |
| bingbot | أساس الزحف والفهرسة الذي تستند إليه تجارب Bing وCopilot | يبقى مسموحاً؛ لم نضف noarchive/nocache عامة تقلل قابلية استخدام المحتوى في الإجابات |
| OAI-SearchBot | اكتشاف مواقع في ChatGPT Search | سماح صريح بالمحتوى العام مع تكرار استثناءات الإدارة وAPI |
| GPTBot | محتوى قد يستخدم لتدريب نماذج OpenAI الأساسية | لم نضف سماحاً أو منعاً خاصاً؛ تبقى القاعدة السابقة `*` كما هي |
| ChatGPT-User | استرجاع بطلب المستخدم؛ ليس زاحف فهرسة البحث، وقد لا تسري عليه robots.txt | لا يُعامل كإثبات لفهرسة ChatGPT؛ تحسين وصول Metadata فقط |
| PerplexityBot | اكتشاف المواقع وربطها في البحث؛ ليس لتدريب النماذج الأساسية بحسب المزود | سماح صريح بالمحتوى العام مع استثناءات خاصة مكررة |
| Perplexity-User | جلب بطلب المستخدم، وليس زحفاً آلياً للتدريب أو الفهرسة | تحسين قراءة HTML، مع إبقاء المصادقة والصلاحيات مستقلة عن robots |

لم تُعدّل قواعد WAF/CDN أو قوائم IP في حساب الاستضافة. تطابق User-Agent في اختبار HTTP لا يثبت أن عنوان IP حقيقياً تابعاً لأحد المزودين اجتاز WAF. robots.txt ليس بديلاً عن حماية البيانات الخاصة.

أضيف `/llms.txt` كدليل قصير اختياري إلى الأقسام العامة فقط، مع التنبيه إلى المصادر وحالة البيانات وسنوات القياس. لا يحتوي سجلات أشخاص أو جهات اتصال أو بيانات خاصة. يُنشأ من أصل الموقع المركزي حتى لا تتقادم روابطه عند تعديل إعداد النطاق. لا يغير ترخيص المحتوى أو سياسة التدريب. لا يُحتسب وجوده دليلاً على الفهرسة أو الاستشهاد؛ Google تصرح أنها لا تستخدمه كإشارة ظهور أو ترتيب.

## المحتوى والبيانات المنظمة

- Organization يصف المبادرة بالنبذة الموجودة فعلياً في إعدادات الموقع ويربط حسابات التواصل العامة المعروضة. لا جوائز أو شراكات أو صفة حكومية مضافة.
- WebSite يحدد الاسم واللغة والناشر والعنوان. لم يُضف SearchAction لمجرد الزخرفة أو وعد بميزة نتائج بحث.
- BreadcrumbList يعكس الهيكل الفعلي وروابط الأدلة/الرجوع، مع عناوين الصفحات الحالية.
- PublicationIssue هو نوع مناسب للعدد الكامل من المجلة؛ لا Article وهمي دون مقال ومؤلف وتاريخ حقيقيين.
- VideoObject لا يظهر إلا مع فيديو قابل للعرض وعنوان ووصف وصورة وتاريخ نشر فعلي. لا تواريخ مبنية على وقت build ولا صور فيديو مخترعة.
- Person محجوب للكتالوج التجريبي. السنوات المتاحة تُعرض كنص في الصفحة ولا تتحول إلى تواريخ ميلاد/وفاة مختلقة.
- Dataset لا يظهر لمؤشر فارغ أو متعارض أو بلا مصدر/منهجية أو بتعريف خارج 50–5000 حرف بحسب متطلبات Google. لا نسبة ملكية للمبادرة ولا ترخيص لإعادة استعمال بيانات الغير دون دليل. الترميز يستند إلى جدول HTML المعروض.
- JSON-LD يحول `<` وUnicode separators إلى تسلسلات آمنة، مع اختبار نص CMS يحاول إغلاق script.

الجدول المضاف يشرح القيم الوطنية المعتمدة فقط. لا يمثل بيانات المحافظات، ولا يخلط سلاسل المصادر، ولا يعوض القيم المفقودة أو يختلق الصفر. آخر تحديث للسجل لا يستخدم بدلاً من سنة القياس. لا أرقام اقتصادية جديدة أضيفت ضمن هذا المسار.

## تقدير داخلي مقترح للمدير

لا تحل هذه الدرجات محل نتائج الاختبارات ولا تمثل درجة Lighthouse. تُراجع بعد الاختبار المتكامل ولا تُرفع لإعلان الجاهزية.

SEO من 15: أصل URL والبيئة 0→3/3؛ عناوين/وصف/لغة ومشاركة 2→3/3؛ زحف وSitemap واستثناءات 1.5→2.5/3؛ بيانات منظمة/تنقل 1→2.5/3؛ حالات HTTP والتحقق من النشر ومتابعته 0.5→2/3. الإجمالي المقترح 5.5→13/15 بعد اجتياز فحص 404 النهائي. الرصيد المتبقي يرتبط بتحقق النشر وRich Results ولوحات الفهرسة وجودة المحتوى.

2. تأكيد `NEXT_PUBLIC_SITE_URL=https://967-initiative.vercel.app` وبيئة Vercel production، ثم فحص Canonical والترويسات في النطاق المنشور والمعاينة.

4. توثيق الملكية في Search Console وBing Webmaster Tools، إرسال Sitemap، وفحص الصفحة الرئيسية وعينات حقيقية من التفاصيل والمعاينات المستثناة.
5. تشغيل Rich Results Test على فيديو/مؤشر/عدد حقيقي يستوفي الحقول؛ النتائج المؤهلة ليست ضماناً للعرض.
6. فحص سجلات Vercel/WAF باستخدام بيانات IP الرسمية المتجددة، ومتابعة مرات الظهور والإحالات والاستشهادات مع تاريخ وسؤال وURL واضح لكل رصد.
