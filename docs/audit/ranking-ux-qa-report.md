# ترتيب اليمن — تنفيذ الواجهة وضمان الجودة

التاريخ: 17 أكتوبر 2026. النطاق: الواجهة العامة لـ`/yemen-ranking`، مع اختبار قراءة البيانات العامة فقط. لم تُجرَ عمليات كتابة في قاعدة الإنتاج أو نشر.

## ما نُفّذ

- واجهة عربية RTL متسقة مع هوية 967، لاختيار المجال والمؤشر وسنة القياس والنطاق العالمي أو العربي.
- مرتبة اليمن والقيمة الأصلية والوحدة وسنة القياس والتغطية ضمن HTML المعروض من الخادم؛ لا ينتظر المحتوى الأساسي تشغيل JavaScript.
- توضيح صريح أن المقارنة محسوبة من القيم المتاحة للدول والاقتصادات في السنة نفسها، وليست تصنيفاً رسمياً صادراً عن البنك الدولي. الاتجاه المرغوب منفصل عن ترتيب القيم؛ المؤشرات السياقية لا تقدم حكماً أخلاقياً أو تقييماً عاماً للدول.
- أقرب خمسة مواضع لليمن، بشريط للقيم يوضح الصفر والقيم السالبة، وتمييز اليمن، وتوضيح تغير عدد الجيران عند بداية القائمة أو نهايتها. تظهر المراتب المشتركة كما حسبها محرك البيانات.
- شريط لموضع اليمن، وتنقل بين السنوات الفعلية فقط، ورسم خفيف للقيم التاريخية دون وصل سنوات مفقودة.
- مقارنة القيم الأصلية لليمن بدولة مختارة، مع السنة والوحدة والفرق. فرق النسب المئوية يوسم بالنقاط المئوية.
- جدول موسع قابل للبحث بالاسم أو الرمز، وحالة فارغة، وزر يعيد البحث والتركيز إلى صف اليمن.
- رابط قابل للمشاركة يحفظ المؤشر والسنة والنطاق والمقارنة، ودعم الرجوع في المتصفح، وحافظة مع مسار نسخ يدوي عند الرفض.
- تنزيل CSV للقيم الأصلية والمراتب والوحدة والسنة والمصدر، وبطاقة PNG عربية تشمل الترتيب والقيمة والسنة والنطاق والجيران ورابط المصدر.
- تحميل المؤشر المختار فقط، وتخزينه مؤقتاً في الجلسة، وإلغاء الطلب السابق، ومنع استجابة متأخرة من استبدال الاختيار الحالي. تتحقق الواجهة من هوية البيانات وصحتها قبل عرضها.
- خطأ واضح مع إعادة محاولة، وعدم إسناد ترتيب وهمي عند غياب قيمة لليمن، مع انتقال اختياري إلى أحدث سنة متاحة له.
- إسناد إلى WDI ورابط المؤشر، وتاريخ تحديث المصدر، وتفاصيل قابلة للفتح للجهات الأصلية وتعريف المصدر وملاحظاته. لا توجد دعوى بترخيص موحد لكل السلاسل.

## عيوب اكتُشفت خلال التحقق وأُصلحت

| المعرف | الخطورة | المشكلة | الإصلاح والتحقق |
|---|---|---|---|
| RUX-01 | P1 | أربع حالات React 418 عند إعادة فتح الصفحة؛ عنوان نقطة SVG المؤلف من عدة JSX children كان فارغاً في SSR وممتلئاً في المتصفح | تمرير نص واحد إلى `<title>`؛ مقارنة فعلية لـDOM الخادم دون JavaScript وDOM بعد التفعيل على بيئة التطوير أثبتت التطابق الكامل وصفر أخطاء. أضيف تحقق HTTP بأن لكل قيمة تاريخية عنوان SVG غير فارغ. البناء النهائي: صفر أخطاء runtime عبر السيناريوهات العشرة |
| RUX-02 | P1 | قيم المقارنة الكبيرة تنقسم وسط الرقم عند 390px رغم غياب overflow عام | جعل بطاقتي المقارنة متتاليتين عند ≤480px وضبط الخط مع منع كسر الرقم. تحقق العرض النهائي عند320 و390px يثبت عدم تجاوز النص بطاقته وبقاءه `nowrap`؛ روجعت صورة390px بصرياً والقيمتان كاملتان |
| RUX-03 | P2 | وصف التغطية يسمي كل عناصر سجل WDI دولاً، مع وجود اقتصادات وأقاليم مستقلة في المصدر | توضيح الدول والاقتصادات في البطاقة والتغطية والجدول والمنهجية |
| RUX-04 | P2 | فقرة الجهة الأصلية الإنجليزية الطويلة تطيل الصفحة على الهاتف قبل الوصول للتذييل | إبقاء المصدر وتاريخه ظاهرين، ونقل النص الكامل للجهات والتعريف والملاحظات إلى تفاصيل أصلية قابلة للفتح |

الجولة الأولى المحفوظة في `evidence/ranking-browser-before-hydration-fix.json` نجحت في عشرة سيناريوهات وظيفية لكنها كشفت أربع أخطاء hydration. لم تعتبر تلك الجولة اجتيازاً نهائياً.

## الاختبارات

`node --test tests/ranking-ui.test.mjs`: ثلاثة اختبارات ناجحة، دون فشل: حفظ حالة الرابط والأرقام العربية، أشرطة السالب والصفر والموجب، وعدم اختلاق قيم أو سنوات في تاريخ اليمن.

ESLint على المكون والمساعد: صفر أخطاء أو تحذيرات في الفحص الأخير.

`node scripts/test-ranking-browser.mjs` يفحص:

1. جميع مؤشرات الكتالوج: 39 منشوراً باستجابة 200، ومؤشر القراءة والكتابة غير المنشور باستجابة 404، مع التحقق من هوية كل snapshot وصحته.
2. وجود المرتبة والقيمة الأصلية وعناوين التاريخ داخل HTML الخادم.
3. النطاقين العالمي والعربي بنفس سنة القياس، والقيم الأصلية للدولة المختارة.
4. العرض عند 320 و390 و768 و1440px، وعدم اقتطاع عناصر التحكم أو الأرقام، وaxe عند 390 و1440px.
5. الجدول والبحث والحالة الفارغة والعودة بالتركيز إلى اليمن.
6. CSV وPNG ورابط المشاركة بعد رفض الحافظة.
7. منزلق السنوات الفعلية والرجوع بين المؤشرات.
8. سنة دون قيمة لليمن والعودة لأحدث سنة له.
9. فشل API مؤقت، وبيانات غير مطابقة، وإعادة المحاولة، وسرعة تغيير الاختيار مع استجابة قديمة متأخرة.

## نتائج البناء النهائي

أعيد تشغيل `node scripts/test-ranking-browser.mjs` على بناء الإنتاج المحلي الأخير: **10/10 سيناريوهات ناجحة، 40/40 تحقق API ناجحاً (39 مؤشراً منشوراً 200 ومسودة404)، 4/4 مقاسات دون تجاوز أو اقتطاع، وفحصا axe دون مخالفات، وصفر أخطاء runtime**. تحقق HTML بأن العناوين التاريخية غير الفارغة موجودة لجميع قيم اليمن اجتاز الفحص، إلى جانب المرتبة والقيمة الأصلية في SSR.

الدليل التفصيلي: [`evidence/ranking-browser.json`](evidence/ranking-browser.json). صور الواجهة [`390px`](evidence/ranking-390.png) و[`1440px`](evidence/ranking-1440.png)، والبطاقة [`PNG`](evidence/ranking-card.png)، والبيانات [`CSV`](evidence/ranking-data.csv).

روجعت صورة390px والبطاقة بصرياً بعد البناء الأخير. قيم المقارنة `41,773,878` و`118,365,995` ظاهرة كاملة. بطاقة1440×1030 تعرض سكان اليمن سنة2025، والمرتبة5 من22 في النطاق العربي، والقيمة41,773,878، والجيران الخمسة ورابط WDI والتوضيح أن المرتبة تحليلية وليست تصنيفاً رسمياً. اختبار CSV يتحقق من رمز اليمن والسنة ورمز المؤشر ورابط المصدر. لا تستبدل هذه اللقطة تعريف المصدر أو سنة القياس عند استخدام مؤشر آخر.

مراجعة الملف والصور الناتجة مطلوبة بعد كل تغيير في التخطيط أو التصدير؛ نجاح تنزيل الملف وحده ليس تحققاً بصرياً.

## القيود

الفحص الآلي عبر Chromium، وليس تجربة هاتف فعلي أو Safari/VoiceOver/NVDA. قد تتبقى حالات تباين SVG ضمن `incomplete` في axe؛ لا توصف بأنها اجتازت فحص أداة آلياً. المقارنة تعتمد التغطية المتاحة لكل سنة، وقد تتغير التقديرات لدى المصدر في تحديث لاحق. لا تدعي الواجهة قابلية مقارنة مرتبتين زمنيتين دون مراجعة التغطية والقيم والتعريف.

الأعلام رموز Unicode زخرفية؛ قد تعرض بعض الأنظمة رمزي الدولة بدلاً من العلم، والاسم النصي يبقى ظاهراً. رسوم التاريخ لا تستكمل السنوات المفقودة، والمراتب في العرض يحسبها محرك البيانات بقيمها الأصلية قبل تقريبها للقراءة.
