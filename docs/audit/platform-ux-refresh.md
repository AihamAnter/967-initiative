## ما تغيّر

- توسيع الرئيسية والترويسة والتذييل إلى 1360px، ومجموعات المحتوى الرئيسية إلى 1280px. بقيت المقالات والقارئ والنماذج بعروضها المناسبة، مع حد لطول الفقرات.
- تقوية عنوان البداية وتوضيح البحث والروابط السريعة. معاينة الأطلس كبيرة على الكمبيوتر ومختصرة على الهاتف حتى تظل الأقسام قريبة.
- استبدال معاينة PNG الداكنة في الرئيسية بـSVG مشتق من **بيانات حدود الأطلس الموجودة نفسها**، بما فيها الجزر. لا تغيير للخريطة التفاعلية أو بياناتها. السكربت `scripts/generate-yemen-preview.mjs` يعيد توليد الأصل.
- شبكة وصول سريع: ستة أعمدة على الشاشات الواسعة، ثلاثة على المتوسطة، وعمودان على الهاتف. رفع الوصف إلى 14px والعناوين إلى 17px، مع أهداف لمس مريحة وتركيز مرئي.
- ملء شبكة أحدث الأعمال بحسب عدد الأعمال المتاح بدلاً من ترك عمود فارغ. صور بنسبة 16:9، وعناوين وتواريخ وبيانات وصفية أكبر. عند غياب الصورة أو فشلها يظهر عنوان العمل وموضوعه ومنصته في تصميم بديل؛ الرابط الحالي للعمل محفوظ.
- غلاف المجلة بحجم أوضح، وتخطيط مستقل على الهاتف، وتاريخ دلالي وزر «اقرأ العدد». لم تتغير روابط القراءة والتنزيل أو معالجة العدد التجريبي.
- إبراز الأرقام وفصل وحداتها، مع اتجاه مستقل للقيمة ومصدر وسنة بخط مقروء. لا أرقام أو تغيرات أو رسوم اتجاه جديدة.
- تحسين معاينة «اكتشف اليمن»، وبطاقات المجتمع، وقراءة «من نحن»، وتحويل المشاريع إلى ثلاث بطاقات تحمل الحالات الفعلية الموجودة.
- تحسين أحجام حقول البحث والفلاتر وحالات الفراغ، وروابط التذييل والمشاركة. ربط أيقونة المتصفح بالشعار الرسمي الموجود لإزالة طلب favicon المفقود.
- الحفاظ على الخلفية الكريمية والبترولي والأخضر والخط المحلي والشعار، وتقليل الحركة بحسب إعداد المستخدم. لا اعتماديات جديدة.

ملفات التنفيذ: `app/platform-refinements.css`، `app/page.jsx`، `app/layout.jsx`، `components/WorkCard.jsx`، `components/WorkThumbnail.jsx`، ومعاينة SVG وسكربت توليدها.

## قياس الأداء وحدوده

عينة Lighthouse واحدة بمحاكاة الهاتف على بناء الإنتاج المحلي، دون تشغيل فحوص المتصفح الأخرى بالتزامن:

|---|---|
| Performance | **71** |
| Accessibility / Best Practices / SEO | **100 / 100 / 100** |
| FCP | 2.26 ثانية |
| LCP | **4.78 ثوانٍ** |
| CLS | **0.00248** |
| TBT | 160.5ms |
| استجابة مستند الخادم | **4.27 ثوانٍ** |
| حجم النقل الكلي | نحو 713KiB |

[تقرير Lighthouse المرئي](evidence/ux-refresh/lighthouse.report.html)، [البيانات الخام](evidence/ux-refresh/lighthouse.report.json).

كُتب التقريران كاملين دون `runtimeError`. بقي أمر Lighthouse CLI قيد التشغيل بعد حفظهما فأُوقف يدوياً؛ الأرقام أعلاه مستخرجة من التقرير المحفوظ، ولا يُسجّل خروج CLI بوصفه ناجحاً.

عنصر LCP هو فقرة البداية؛ تفصيل Lighthouse ينسب نحو 4.28 ثوانٍ إلى انتظار أول بايت ونحو 0.53 ثانية إلى تأخر العرض. تظل استجابة الخادم وجلب البيانات نقطة تحسين مستقلة. **لا ادعاء بتحسن الدرجة عن القياس السابق أو اجتياز Core Web Vitals**؛ القياس السابق في تقارير 16 أكتوبر ليس خط أساس مطابقاً لهذه الجولة. INP الميداني لم يُقَس.

أصل معاينة SVG حجمه 134231 بايت (28970 بايت عند gzip)، مقابل 2053902 بايت لأصل PNG السابق. هذه مقارنة **أصول الملفات**، وليست ادعاءً بأن حجم النقل انخفض بهذه النسبة؛ Next كان يحسّن صورة PNG سابقاً. لم تُضف مكتبات تجميلية أو مشغلات ثقيلة، وتظل الصور خارج البداية مؤجلة.

## حدود التحقق

- الاختبارات على Chromium محلي، وليست Safari/Firefox أو أجهزة فعلية أو قارئ شاشة. axe لا يعوّض اختبار الوصول اليدوي الشامل.
- الجولة الأولى داخل البيئة المقيدة سجلت طلبات Supabase محجوبة وأيقونة مفقودة؛ حُفظت في `iteration-responsive-results.json`. أُصلح رابط الأيقونة وأُعيد الفحص مع السماح بقراءة الموارد العامة، وكانت نتيجة التسليم بلا أخطاء أو طلبات فاشلة.
- لم تُختبر كتابة الإنتاج أو تسجيل الدخول بأدوار فعلية أو تشغيل كل فيديو لدى مزوده الخارجي. التحقق من نموذج التواصل كان محلياً بطلبات معترضة.
- لم تتغير قاعدة البيانات أو RLS أو بيانات الإنتاج أو وظائف الإدارة. لم يُدفع الفرع ولم يُنشر على Vercel. تبقى القيود السابقة المتعلقة بالإدارة وRLS واعتماد المحتوى كما هي موثقة في تقارير التدقيق السابقة.

لإعادة فحص الواجهة: شغّل بناء الإنتاج محلياً ثم `$env:CHECK_BASE_URL='http://127.0.0.1:3102'; node scripts/test-platform-responsive.mjs`. يعتمد سكربت الفحص على أدوات QA المعزولة الموجودة في `.audit-tools`، ولا يضيفها إلى اعتماديات الموقع.
