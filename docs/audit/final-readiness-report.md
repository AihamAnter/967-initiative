## أهم عشرة تحسينات نُفّذت

1. تحديث Next.js وPDF.js وPostCSS المتأثرة، مع runtime متوافق؛ تدقيق حزم تشغيل الإنتاج الآن **صفر ثغرات معروفة**.
2. قارئ طلبات JSON محدود أثناء التدفق، تحقق origin كامل، رفض الأنواع والأحجام غير المناسبة، مهلات وCache-Control وحماية HTTP أساسية. اجتاز API **27 فحصاً**.
3. توحيد تحقق أدوار الإدارة عبر POST/PATCH/DELETE، منع التخفيض الذاتي وآخر مدير في المسار التسلسلي، تنظيف حالة الجلسة، وتصحيح زر تحديث الإدارة. الحماية من سباق متزامن تحتاج SQL المقترح.
4. تواقيع ملفات الرفع وMIME والامتداد والحجم، روابط آمنة، تعطيل scripts/eval في قارئ PDF، وفحص محلي لقيمة service-role في **60 ملف عميل دون تسريب**.
5. Metadata مركزية وفريدة، Canonical إنتاجي صحيح، OG/X ولغة عربية، حماية المعاينات والإدارة والنماذج من الفهرسة، Sitemap ديناميكي وروبوتات بحث موثقة.
6. JSON-LD صادق وآمن، استبعاد Person للنماذج، وجدول إحصائي SSR مع القيم والسنوات والوحدات والمصادر. مؤشر فعلي أثبت HTML وDataset دون JavaScript.
7. استجابات **404 حقيقية** للتفاصيل غير الموجودة بعد نقل حدود التحميل الموروثة إلى أوراق لا تحتوي تفاصيل ديناميكية.
8. إصلاح PDF متعدد الخانات والأرقام العربية والأزواج والصفحة الأخيرة، نص مقروء بديل، إعادة محاولة وفشل مفهوم؛ وخريطة بحدود zoom سليمة وتنقل لوحة مفاتيح وإخفاء مديريات يعمل فعلاً.
9. تحسين قائمة الهاتف والفلاتر والبطاقات والتركيز والدلالات. اجتازت **152 حالة عرض** و**38 فحص axe** دون مخالفات مرصودة، مع **11 فحصاً إضافياً للفلاتر**.
10. تصدير CSV آمن من صيغ الجداول وPNG يعرض الرسم الحقيقي مع العنوان والفترة والوحدة والمصدر؛ استضافة الخطوط محلياً وتقليل طلبات pagination وتحسين CLS إلى **0.0035**.

المقارنة الأساسية محلية، على إعداد Lighthouse mobile نفسه، بعينة مختبرية قبل وعينة بعد. النسخة المنشورة بقيت كما هي، وخط أساسها مستقل: Performance60،LCP4.49s،CLS0.525.

تحسن الثبات ودرجة الأداء وFCP؛ لا ادعاء بتحسن كل مقياس. حجم النقل وTBT زادا في العينة، والحزمة المشتركة بقيت103kB. **LCP ما زال فوق هدف2.5s** ويحتاج قياساً في منطقة الاستضافة الحقيقية ومتابعة زمن جلب البيانات. ظهرت مهلات إعدادات الموقع أحياناً أثناء القراءة الجماعية؛ يستخدم التطبيق الإعدادات الافتراضية عندها. لم نضف cache يعرض بيانات تحريرية قديمة لإخفاء التأخر.

**INP الميداني لم يُقَس، وTBT ليس INP.** لذلك لا ادعاء اجتياز Core Web Vitals. لا تكفي هذه العينات لاستنتاج تحسن مستخدمي الإنتاج أو النسبة المئوية75. [الشرح الرسمي للقياس المختبري والميداني](https://web.dev/articles/vitals). الأرقام الخام وتفسيرها في [تقرير الأداء](performance-report.md) و[evidence/performance-comparison.json](evidence/performance-comparison.json).

## SEO والبحث بالذكاء الاصطناعي

قابلية الزحف التقنية وMetadata وHTML والروابط والمصادر تحسنت واجتازت الفحص المحلي. noindex يحمي الإدارة والبحث والنماذج والمعاينات؛ يجب إعادة التحقق على عنوان Vercel production وPreview بعد النشر المصرح. المجموعة الخاصة لروبوتات البحث تكرر الاستثناءات الخاصة، ولم تتغير سياسة التدريب القائمة.

`llms.txt` دليل اختياري منخفض الصيانة؛ لا شرط رسمي ولا ضمان اقتباس. **الفهرسة المؤكدة والظهور المؤكد والاستشهاد الفعلي غير مثبتة.** انتحال User-Agent للاختبار لا يثبت زيارة زاحف حقيقي أو اجتيازه WAF. تفاصيل الوثائق الرسمية والسياسات والأدلة في [seo-ai-report.md](seo-ai-report.md).
