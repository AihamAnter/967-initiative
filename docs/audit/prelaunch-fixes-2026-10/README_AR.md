# التقرير النهائي — مراجعة منصة 967 قبل الإطلاق

23 أكتوبر 2026 · الفرع `fix/prelaunch-quality-34` · مصدر المقارنة `6158419`.

## أ. ملخص تنفيذي

نُفذت الإصلاحات المحلية الممكنة في المناظرات والنقاش والمسودات والإبلاغ، ومتابعة الرسائل والصلاحيات، وحماية آخر حساب Management، والرئيسية والمجلة والأدلة والخريطة، والبحث وSitemap وتشخيص الأخطاء. لم يتغير المحتوى التجريبي أو التحريري أو المراجع أو بيانات التصويت أو دقته وقواعده وعرض نتائجه.

المحصلة: **27 Fixed، و2 Verified، و5 Partially Fixed**. الكود **READY FOR REVIEW**. لم تُطبّق migrations على الإنتاج، ولم تُعدّل بياناته أو تُنشر نسخة. فحص L-01 الإنتاجي استخدم GET للقراءة فقط.

## ب. جدول المشكلات الـ34

[السجل الكامل](issue-register.md) يعرض المعرف والعنوان والخطورة والحالة الأصلية والدليل والملفات والسبب الجذري والإصلاح والاختبار ونتيجته والحالة النهائية والمتبقي لكل بند. تعني Fixed نجاح الإصلاح والتحقق المحلي المحدد؛ ولا تعني اكتمال النشر أو الاختبارات المستضافة.

## ج. أهم التغييرات

- تظهر المناظرة المباشرة تحت «تُبث الآن» مرة واحدة، ولا يُقدّم الموعد الماضي بوصفه موعداً مستقبلياً.
- يرى قارئ آخر التعليق الجديد والإخفاء وتحديث حالة السؤال دون F5، مع بقاء المسودة والفلتر وموضع القراءة.
- تعود مسودة الزائر بعد الدخول، ولا تنتقل إلى حساب آخر أو تُنشر تلقائياً. لا تُنقل ملكيتها إلى معرّف signup مموه دون جلسة.
- يفتح زر الشركة طلب تصحيح مرتبطاً بها، وتصل الرسالة المحفوظة للإدارة بحالة متابعة. ضياع استجابة الحفظ ثم تعديل النص لا يؤدي إلى تأكيد كاذب لنص قديم.
- لا يتكرر أحدث عدد في الأرشيف، وتقدم الرئيسية المحتوى مبكراً مع إبقاء الوصول إلى جميع الأقسام.
- لا يؤدي فشل مصدر واحد إلى سقوط Sitemap أو جميع نتائج البحث، وتستبعد السجلات التشغيلية البيانات الحساسة.

راجع [تقرير التنفيذ والملفات الرئيسية](implementation-report.md).

## د. تقرير الاختبارات

**272 اختباراً ناجحاً، وصفر فشل أو تخطٍّ** في المجموعة النهائية مع PostgreSQL الحقيقي. نجح بناء الإنتاج، ونجح Lint بصفر أخطاء وثلاثة تحذيرات `<img>` سابقة.

فُحصت المنصة على 21 مساراً، عبر 147 قياس عرض و42 فحص axe و21 حالة تكبير نص إلى 200%، دون تمرير أفقي أو أخطاء تشغيل أو hydration مكتشفة. أُجريت أيضاً 12 رحلة UX، و15 سيناريو للمناظرات، و7 رحلات للتواصل والإدارة. لا تُجمع الاختبارات المعادة أو القياسات المتداخلة مع العدد 272 لتضخيمه.
