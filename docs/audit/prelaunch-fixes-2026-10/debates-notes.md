## L-01 — النشر الفوري في الإنتاج

الكود وmigrations الإصلاح السابقة موجودة، واختبارات PostgreSQL المعزولة تثبت النشر المباشر مع احترام الإخفاء. فحص المشرف الحالي **GET فقط** في `evidence/production-publication-readonly.json` أظهر defaults = approved للأسئلة والتعليقات ووجود lifecycle وRPC ذي UUID صفري يعيد null مع HTTP 200. بذلك لم يعد دليل pending القديم دليلاً على الوضع الحالي. لا يكشف هذا الفحص body دوال PostgreSQL، ولا يثبت رحلة كتابة فعلية على الإنتاج؛ الحالة **Partially Fixed / Verified metadata**، والمتبقي تحقق staging بحسابات اختبار مصرح بها أو مراجعة function definitions من المشروع الصحيح. لا حاجة لافتراض تطبيق migration أو إعادة تطبيقها دون هذا التحقق.

## أداء وحدود التحقق

أُزيل `app/debates/loading.jsx` القصير كـancestor streaming fallback بعد تنسيق المشرف. كان يدفع footer المرئي عند وصول صفحة المناظرات الكاملة، وينطبق أيضاً على تفاصيل المناظرة و404. الإزالة متوافقة مع إرشاد README حول leaf loading؛ مكونات النقاش والفيديو تبقي حالات التحميل الخاصة بها. قياس CLS النهائي ومسارات404 بعد البناء مسؤولية الفحص الموحد؛ لا تنسب أرقام baseline إلى قياسنا المحلي في dev.

حفظ المسودة مقصود لنفس علامة التبويب فقط؛ صفحة auth توضح إكمال الدخول في نفس التبويب خلال 30 دقيقة. فتح رابط البريد في تبويب/جهاز آخر لا ينقل النص الخاص تلقائياً. الاختبار المحلي لتأكيد البريد لا يرسل بريداً ولا يثبت SMTP أو Redirect URLs المستضافة. لا توجد بيئة staging أو حسابات إنتاج مصرح بتعديلها ضمن هذا التنفيذ.
