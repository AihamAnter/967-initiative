# ترتيب اليمن — تقرير تنفيذ الخلفية

17 أكتوبر 2026. نطاق متخصص الهندسة: المصدر الثابت، الترتيب، تحميل البيانات، واجهات API، صلاحيات الإدارة وSQL المقترح. لم تُنفذ كتابة إلى قاعدة الإنتاج، أو دعوات مستخدمين، أو نشر للموقع.

## ما نُفذ

- `lib/rankings.js`: ترتيب سنة واحدة ونطاق عالمي/عربي، باتجاه تصاعدي أو تنازلي؛ الصفر والقيم السالبة محفوظان. التعادل بنظام المنافسة `1,2,2,4`، وعدد المتعادلين ظاهر في `tieCount`. فصل التعادل حسب ISO3 بترتيب ASCII ثابت يمنع اختلاف ICU بين الخادم والمتصفح. السنة الافتراضية أحدث سنة متاحة **لليمن**، ولا تستعير سنة من بلد آخر. جوار اليمن يعرض حتى خمسة بلدان مع الحفاظ على الرتب الأصلية.
- `lib/rankingProvider.js`: طلبات HTTPS إلى `api.worldbank.org` فقط، مع منع redirects، والتحقق من رمز المؤشر ووجوده في مصدر2/WDI. تحميل جميع الصفحات وفق totals الحقيقية؛ رفض التحميل الجزئي والتكرار وتغير metadata أثناء الجلب. استبعاد المجاميع بحسب `region.id = NA`، وحفظ أسماء البلدان/الاقتصادات بالعربية. لا تحويل للقيم المفقودة إلى صفر ولا إدراج لسنوات مستقبلية.
- `source.updatedAt` هو تاريخ تحديث المصدر؛ `fetchedAt` وقت تنزيل النسخة؛ أحدث قياس لليمن حقل مستقل. حُفظت `sourceOrganization` و`sourceNote` لدعم نسب البيانات إلى مزوديها الأصليين ومراجعة الاستثناءات الترخيصية، دون افتراض رخصة واحدة لكل المؤشرات.
- `lib/rankingRepository.js` و`rankingData.js`: فصل مصدر البيانات عن التخزين، والتحقق من توافق payload مع رمز المؤشر؛ JSON المحلي محدود الحجم ومساره مشتق من slug مقيد. فقدان جداول ranking المحدد يعرض النسخ المرفقة؛ أخطاء الشبكة/الصلاحية/الأعمدة لا تتحول إلى fallback صامت. الدليل الموجود الفارغ أو الذي أخفى المحرر كل عناصره يبقى فارغاً. يمكن للمؤشر المزروع الذي لا يملك snapshot استخدام ملف مرفق يطابق **slug والرمز معاً**؛ المؤشر المخصص أو الرمز المعدل لا يستعير ملف مؤشر آخر.
- `ranking_snapshots.summary` يقدم ملخص التغطية للإدارة دون تحميل جميع JSON التاريخية إلى قائمة الإدارة. `countryCount` عدد البلدان ذات القيم، وليس عدد سجلات metadata.

## عقود API

| المسار | العقد |
|---|---|
| `GET /api/rankings?indicator=slug` | `{indicator,dataset}` للمؤشر المنشور؛ `404` للمخفي/المجهول/slug غير الصالح؛ `503` لتعطل الخدمة. قد يكون dataset=null لمؤشر لا يملك نسخة مطابقة. |
| `GET /api/admin/rankings` | bearer صالح ودور admin أو management؛ `{indicators,library,setupRequired,mode}`. الجداول المفقودة تعطي `200` مع setupRequired=true؛ تظل صلاحية المستخدم مطلوبة. |
| `POST /api/admin/rankings` | `{indicator,expectedUpdatedAt?}`؛ إنشاء/تعديل الحقول المعروفة فقط؛ `201/200` مع `{ok:true,indicator}`؛ تعارض نسخة أو slug يعطي409. CAS عند إرسال expectedUpdatedAt يستخدم `updated_at` داخل استعلام التعديل نفسه. |
| `POST /api/admin/rankings/refresh` | `{id}`؛ يجلب المصدر الثابت ويحفظ snapshot وsummary، **ولا يغيّر حالة النشر**. يرفض تغير رمز المؤشر أثناء الجلب. يعيد `{ok:true,indicator,snapshot}`؛ حد دالة Vercel60 ثانية. |

الأخطاء JSON من الشكل `{error:رسالة}`. جميع الاستجابات `Cache-Control:no-store`. واجهات الإدارة ترفض origin غير مطابق وطلبات cross-site قبل أي تعديل؛ تحقق الجلسة server-side ثم صف editors ودور معروف. الجسم محدود بالبايت وJSON كائن فقط. لا DELETE إداري؛ يستخدم المحرر حالة النشر.

## قاعدة البيانات

`supabase/yemen-ranking.sql` مقترح إعداد **غير مطبق**، ويحتاج schema.sql وadmin-roles.sql. يضيف ranking_indicators وranking_snapshots وفهارس وتواريخ تحديث وقواعد RLS:

- الجمهور يقرأ المؤشرات المنشورة ونسخها فقط.
- المحرر المعتمد يقرأ المسودات.
- لا منح INSERT/UPDATE/DELETE مباشر لحسابات anon/authenticated؛ الكتابة تمر عبر API يتحقق من الدور قبل service key المحصور بالخادم.
- لا تزرع migration المحتوى تلقائياً ولا تغيّر أدوار مستخدمين أو تحذف بيانات قائمة. ملف seed الذي أعده المدير منفصل ولم يطبقه هذا الوكيل.

## القيود الصريحة

لم تُطبق SQL ولم تُختبر صلاحياتها فعلياً بحسابات editor/management، ولم تُنفذ كتابة إدارية ناجحة أو refresh محفوظ في قاعدة معزولة لعدم وجود staging وحساب اختبار. اختبارات رفض HTTP والمحاكاة لا تثبت نجاح الكتابة الفعلية أو optimistic concurrency على Postgres. يجب تشغيل SQL بعد مراجعته في بيئة آمنة والتحقق من هذه السيناريوهات قبل اعتماد تشغيل الإدارة بالكامل.

الترتيب حساب للمنصة اعتماداً على القيم المتاحة في السنة المحددة، وليس ترتيباً عالمياً رسمياً منشوراً من البنك الدولي. التغطية ليست كل دول العالم لكل مؤشر/سنة؛ تصنيف البنك يشمل بلداناً واقتصادات، وسنوات اليمن متأخرة في بعض المؤشرات. يجب قراءة اتجاه المؤشر ووحدته ومنهجيته بدلاً من افتراض أن المرتبة الأعلى أفضل دائماً.
