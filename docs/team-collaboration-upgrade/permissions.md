المسؤول والمشارك علاقتان بالمهمة، وليسا دورين جديدين للحساب. إزالة مشارك تسحب صلاحية إكمال خطوات المهمة وتنبيهات عضويتها، وتبقي القراءة والتعليق اللذين يملكهما أصلًا بصفته محررًا. إزالة دور التحرير تمنع الوصول حتى إن بقي مرجع تاريخي له.

تُطبق القيود في RLS وTriggers/RPC والخادم ثم الواجهة. المشارك لا يغير حالة المهمة الرئيسية ولا يحذفها أو يعيد إسنادها أو يعتمد مراجعتها. قيود الحذف والنشر للمحتوى الأصلي تبقى كما كانت؛ السجل لا يمنح صلاحيات تحرير إضافية.

API المساهمات يعيد التحقق من الجلسة وتأكيد البريد والإيقاف والدور. دالة القراءة وسياسات الجدولين تعيد فحص ذلك في قاعدة البيانات. Admin وManagement يقرآن سجل جميع الأعضاء؛ المستخدم العادي لا يقرأ الأحداث ولا المجاميع عبر RPC.

يسمح مفتاح الخدمة باستدعاء RPC المحدد بعد تحقق الخادم، ولا يملك INSERT/UPDATE/DELETE مباشرًا على جدول المساهمات. لا يقبل RPC من authenticated هوية محرر بديلة. أسماء وUUID أعضاء الاختبار في الأدلة اصطناعية بالكامل.

الاختبارات تشمل رفض الزائر والمستخدم العادي والحساب غير المؤكد والموقوف والمزال دوره، وتعارض النسخة، وتعديل تعليق الغير، وسحب صلاحية إنجاز خطوة بعد إزالة المشاركة. تبقى حماية الأدوار القديمة وManagement ضمن اختبارات المشروع الحالية.
