# مراجعة تجربة المستخدم

قيد التنفيذ. الصور قبل وبعد ستستخدم بيانات محلية اصطناعية، دون حسابات فريق حقيقية أو كتابة إنتاجية، عند 1440 و390 بكسل.

المحاور: شاشة عمل اليوم، الأقسام الشخصية، القائمة وKanban والتقويم، وصف المهمة والخطوات والمناقشة الظاهرة والمشاركون، روابط الردود، Dashboard المساهمات، العودة إلى القائمة وفلاتر الشخصيات دون بحث نصي.

لوحة المساهمات غير موجودة في الإصدار السابق؛ صورة «قبل» لها ستكون لوحة الإدارة والتنقل السابقين، لا لوحة وهمية.
