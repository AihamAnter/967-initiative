# جرد مسارات التحرير والتغطية

حالة أولية قبل التنفيذ؛ جميع المسارات أدناه تتطلب إثبات التغطية باختبارات SQL. لا يكفي ظهور زر الحفظ أو سجل React.

| القسم | مسارات الكتابة القائمة | المطلوب |
| --- | --- | --- |
| المجلة والأعمال | AdminDashboard: insert/delete مباشر؛ update عبر inline_content_save؛ التحرير المباشر نفسه | إنشاء/تعديل/نشر/إلغاء نشر/حذف |
| الشركات | CompanyAdminPanel: insert/delete مباشر؛ update عبر inline_content_save | جميع عمليات الصف والمنتجات JSON |
| المهنيون | ProfessionalAdminPanel: insert/delete مباشر؛ update عبر inline_content_save | جميع عمليات الصف دون تسجيل قيم التواصل |
| المناظرات | debate admin RPC؛ التحرير المباشر؛ جداول المشاركين والفصول والاستطلاعات | المحتوى والتحولات؛ استبعاد أصوات الجمهور والإشراف على حساباته |
| الشخصيات | API figures → ملف خاص ثم inline_service_save | حدث بعد اختيار نسخة السيرة فعليًا؛ فشل الحفظ لا يحتسب |
| الإحصاءات | StatisticsAdminPanel: مؤشرات/مصادر/قيم/روابط ومجموعات استيراد مباشرة | تغطية الجداول وحفظ المؤشر وروابطه ذريًا |
| ترتيب اليمن | API rankings وrefresh → service role: metadata وsnapshot | فاعل متحقق ومعاملة وحيدة لكل حفظ |
| المحافظات والمديريات | inline_content_save؛ API districts → site_settings CAS | كلا المسارين، مع هوية المحرر |
| الصفحات التعريفية | API pages → inline_service_save لكتالوج JSON | أحداث منفصلة للصفحات المتغيرة مع بقاء العنوان والرابط التاريخي |
| الإعدادات العامة والظهور | SiteSettingsPanel upsert؛ API page-visibility CAS | المفاتيح العامة فقط، دون قيم أو أسرار |
| المسودات الخاصة | editor_save_draft / editor_delete_draft | مستثناة من إحصاءات المحتوى |
| أعضاء الفريق والرسائل | API editors/messages | مستثناة من سجل المحتوى؛ تبقى قيود الإدارة الحالية |

تاريخ تفعيل السجل سيُحفظ في الترحيل. لا تُختلق ملكية أو أحداث للمحتوى السابق.
