6. التنقل: عودة سياقية محدودة بالموقع، جاهزة من العرض الأول، مع بديل للقسم عند الدخول المباشر وحفظ موضع القائمة. شمل الفحص الأعمال والمجلة والشركات والمهنيين والشخصيات والمناظرات والمؤشرات والمجالات والبحث والحساب.
