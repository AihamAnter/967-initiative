# قائمة تطبيق ومراجعة النشر

- مراجعة الترحيلات ونسخة احتياطية معتمدة واختبار استعادتها قبل أي تطبيق إنتاجي.
- تطبيق الترحيلات بالترتيب على Staging مماثل للإنتاج؛ التأكد من المهام القديمة والصلاحيات وسجل النشاط والتكرار والأرشفة.
- مراجعة جدول تغطية السجل ونتائج فشل الحفظ والتزامن ومنع الحسابات غير المخولة.
- مراجعة صور الهاتف والكمبيوتر والتنقل ولوحة المساهمات.
- موافقة المستخدم الصريحة مطلوبة لتطبيق SQL على الإنتاج، وموافقة مستقلة للمراجعة والدمج/النشر كما طلب.
- لا Seed ولا إعادة تهيئة ولا تغيير للشعارات والخطوط أو القيم الإحصائية أو الأصوات الحالية.

لم يُنفذ أي بند إنتاجي في هذه المهمة.
