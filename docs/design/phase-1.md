# المرحلة الأولى: أساس الهوية البصرية لـ967

## النطاق

تؤسس هذه المرحلة الألوان والخطوط والمسافات وعناصر العرض المشتركة. تبقى بنية الرئيسية وترتيب أقسامها والخريطة وأحجام شرائحها للمرحلة الثانية، وتبقى إعادة تكوين الصفحات الداخلية للمرحلة الثالثة. الهيدر والناف بار يحتفظان بتنسيقهما وسلوكهما الحاليين.

المعاينة المحلية: `/design-system`. تعرض أمثلة تصميمية مصرحًا بأنها توضيحية، وروابطها تفتح أقسام المنصة. الصفحة موسومة `noindex, nofollow`، ولا تُضاف إلى قائمة التنقل أو خريطة الموقع.

## الملفات والمسؤوليات

- `app/design-tokens.css`: مصدر القيم المشتركة للألوان والخطوط والمسافات والحواف والظلال والحركة وعرض الحاويات.
- `app/visual-foundation.css`: تطبيق الأساس داخل `.visual-foundation` في منطقة المحتوى، مع أشكال أنواع المحتوى. لا يحتوي قواعد لتغيير ترتيب أقسام الرئيسية أو أعمدة القوائم.
- `components/design/ContentSurface.jsx`: غلاف عرض خفيف يعيد عنصر `article`، ويحافظ على مسؤولية البيانات والروابط والتفاعلات في المكونات القائمة. يصدّر أيضًا `ContentBadge` للتصنيفات.
- `components/design/YemeniMotif.jsx`: زخرفة SVG أصلية مستوحاة من القمريات، مخفية عن قارئ الشاشة ولا تعترض النقرات.
- `app/design-system/`: صفحة معاينة مستقلة للألوان والخطوط والنماذج الستة وعناصر التفاعل.

انتقلت تعريفات القيم العامة القديمة من `design-system.css`، وعروض الحاويات من `platform-refinements.css`، إلى ملف القيم الموحد. تبقى قيم التوافق القديمة خارج منطقة المحتوى للحفاظ على الهيدر والتذييل؛ تُربط أسماء الألوان القديمة بالقيم الجديدة داخل منطقة المحتوى فقط. تُعدّل القيم الجديدة في المصدر الموحد بدل إضافة لوحات ألوان مستقلة في كل صفحة.

## الخطوط والمسافات

الخط المستخدم هو IBM Plex Sans Arabic المستضاف محليًا بالفعل، دون تحميل خط أو اعتماد جديد.

- نص أساسي: 17px، بارتفاع سطر 1.9 ووزن 400.
- تصنيفات وروابط: 14px، بأوزان 500–600.
- بيانات مساندة: 13px.
- عناوين البطاقات: 19–23px؛ عناوين الأقسام: 28–40px؛ العناوين الكبيرة: 36–72px بحسب عرض الشاشة.
- مقياس المسافات: 4، 8، 12، 16، 20، 24، 32، 40، 48، 64، 80px.
- حواف منفصلة للأزرار والبطاقات والمجلة، وظل خفيف وحالة تركيز واضحة. الحركة تحترم تفضيل تقليل الحركة.

القيم جاهزة للمرحلتين التاليتين. اقتصر ربط الخطوط حاليًا على النصوص والعناوين المشتركة وبعض نصوص البطاقات، مع إبقاء مقاسات العناوين الخاصة وتخطيطات الصفحات لمراحلها.

## أنواع المحتوى

| `kind` | التمييز |
| --- | --- |
| `video` | مرجاني، حد سفلي، وزخرفة خفيفة عند غياب الصورة |
| `issue` | بنفسجي، حافة تشبه تجليد المجلة، وخلفية للغلاف |
| `debate` | شريط أزرق وأحمر؛ بقاء تمييز المشاركين الحالي |
| `indicator` | حد علوي أزرق وأرقام واضحة بمحاذاة رقمية ثابتة |
| `profile` | تركواز، حافة جانبية، وهوية الشخص في مقدمة النموذج |
| `product` | أصفر، حد سفلي، ومساحة مستقلة للمنتج |

استخدام المكونات داخل منطقة المحتوى:

```jsx
import ContentSurface, {ContentBadge} from '@/components/design/ContentSurface';

<ContentSurface kind="video" className="work-card">
  <ContentBadge kind="video" />
  {/* الصورة والعنوان والروابط والتفاعلات الخاصة بالمحتوى */}
</ContentSurface>
```

رُبط الغلاف بمكونات الأعمال والمؤشرات وأرشيف المجلة والمناظرات والمهنيين والمنتجات. لم تتغير استعلامات البيانات أو روابط التفاصيل أو آلية الحفظ أو الفلاتر. تصميم الغلاف لا يحذف المعلومات ولا يقصها لفرض حجم ثابت.

## التحقق

- نجح `npm run lint` دون أخطاء؛ ثلاثة تحذيرات سابقة تخص `<img>` في `MediaViewer` و`PdfReader`.
- نجح بناء Next.js المعزول باستخدام `NEXT_VALIDATION_BUILD=1`.
- تطابقت قياسات الهيدر وألوانه وخطوطه ومسافاته قبل التعديل وبعده على 390 و768 و1440px.
- نجحت 16 حالة عرض لثماني صفحات على 390 و1440px دون تمرير أفقي أو أخطاء JavaScript.
- نجح حفظ مادة للقراءة لاحقًا، واستمرار حالتها بعد إعادة التحميل، ثم إزالتها في سياق متصفح اختباري معزول.
- أظهر الفحص الأول لتباين المعاينة حاجة نص التصنيف المرجاني إلى درجة أغمق؛ أُضيف رمز لون مستقل للنص لتصحيحها.

أدلة المعاينة والفحوص المحلية في `.audit-tools/visual-phase-1/`. فحوص الإتاحة آلية ومحدودة بالصفحات والمقاسات المذكورة، وليست شهادة مطابقة شاملة. لا تغييرات في قاعدة البيانات أو نشر للإنتاج ضمن هذه المرحلة.
