# مدرسة 967 / قسم المعرفة — المرحلة الثانية: بطاقات التاريخ والشخصيات والأطلس

**النطاق:** `/yemen-history`، `/yemeni-figures`، `/yemen-map` وصفحات الملفات الخاصة بها. المرحلة الثالثة للبيانات والترتيب لم تُنفذ في هذه المهمة.

## ما تغيّر

### تاريخ اليمن
- الوسوم الزمنية والمواد صارت مفصولة بصريًا؛ كل نوع (دولة، حدث، مجتمع، آثار، موقع، موضوع) يملك لونًا هادئًا لا يغطي البطاقة.
- شريط العصور يوضح الاختيار الحالي، وأصبحت منطقة البحث مختلفة عن النتائج.
- الخط الزمني يحتفظ بالتمرير والسحب والمفاتيح ودوائر المحطات، مع لون للعنصر المختار ولون خفيف لنوع المادة.
- داخل الملفات التاريخية: رأس بلون القسم، شريط للمعلومات، قائمة حقائق جانبية، ومراجع ومواقع ذات حدود وخلفيات واضحة.

### شخصيات يمنية
- بطاقات الشخصيات تميز الصورة/الحالة الزمنية/المجال/النبذة/المحافظة بدل وضعها كلها في مساحة بيضاء واحدة.
- خلفيات هادئة لمجموعة المرشحات ووسوم المجالات والفترات.
- داخل ملف الشخصية: خلفية للعنوان، وحقائق جانبية بلون القسم، ومداخل أنعم للملفات المرتبطة.
- بقيت الصور ذات المصادر الموثقة كما هي، وكذلك نسخ صور البروفايل وإتاحة تصحيح المعلومات وروابط التواصل.

### خريطة اليمن
- تم ترقيم بطاقات المحافظات بصريًا من 01 إلى 22، دون تغيير الترتيب أو إنشاء أقسام جغرافية غير مستندة إلى البيانات.
- لوحة معلومات المنطقة تعرض الحقول في بطاقات منضبطة، مع إبراز العناوين والمديريات ومصادر البيانات.
- ملفات المحافظات الطويلة فيها حقائق واضحة، أقسام قراءة بخط رأسي خفيف، تنقل جانبي ومديريات سهلة النقر.
- **لم تتغير** حركة الخريطة، التحريك، التكبير، اختيار المحافظات والمديريات، التحميل، أو التنقل إلى الملفات.

### شريط التنقل
- أصبح شريط أقسام المعرفة موجودًا في ملفات التفاصيل أيضًا، وليس في الصفحة الرئيسية للقسم فقط.

## الملفات
- CSS Modules: `HistoryExplorer.module.css`, `HistoryTimeline.module.css`, `HistoryPage.module.css`, `YemenDiscovery.module.css`, `GovernorateProfile.module.css`.
- CSS عام لكنه محدود: `app/knowledge-content.css` (يعمل فقط داخل `data-knowledge-area`).
- JSX: ملفات التاريخ والخط الزمني وبطاقات المحافظات وثلاث صفحات التفاصيل.
- اختبارات: `tests/knowledge-content-phase2.test.mjs` و `tests/browser/knowledge-stage2.spec.mjs`.

## الحماية وحدود التغيير
لا توجد تغييرات SQL أو ترحيلات أو صلاحيات أو تعديل للخط أو SEO أو بيانات البحث.
لا تغيير في `onGovernorateChange`، `onGovernorateExplore`، `filterFigures`، `getYemeniFigure`، أو درجات التعليم.
