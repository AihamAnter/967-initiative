# تقرير إعادة تصميم منصة 967

> تحديث البحث: بناءً على المراجعة اللاحقة، أصبح المحتوى الظاهر في «اكتشف اليمن» قابلاً للبحث، بما فيه الكتالوج التوضيحي مع بيان حالته. أضيف البحث في نصوص التفاصيل والمحافظات والمديريات ومجالات المرصد وصفحات المنصة. ما زالت المسودات والبيانات الخاصة مستبعدة، ولا يشمل البحث النص الكامل داخل PDF. نجحت الاختبارات الحالية الـ11، ومنها اختبار جميع الشخصيات الـ120، ونجحت 14 حالة تكامل على نسخة الإنتاج المحلية، بما فيها البحث عن أروى والبردوني والأماكن وعناوين حقيقية من جميع أنواع المحتوى واتصال نموذج الرئيسية بالبحث. نجح Build وLint بلا أخطاء، مع التحذيرات التسعة السابقة. يمكن إعادة فحص التكامل باستخدام `node scripts/check-search.mjs` بعد تشغيل الخادم.

## ما تغير فعلياً

- استُبدلت الهوية الداكنة والحمراء بنظام ألوان بترولي وكريمي ورملي وأخضر، مع رموز مركزية في `app/design-system.css` وتكييف الأنماط القائمة معها. استمر استخدام IBM Plex Sans Arabic.
- أُنشئ `BrandLogo` باستخدام ملف الشعار الأصلي ونسبه، مع نسختين لونيتين. أزيلت شعارات الأرقام المتباعدة من الرئيسية.
- أُعيد بناء الرئيسية: مقدمة قصيرة وبحث، ستة مداخل مباشرة، المحتوى المنشور، مؤشرات ذات قيم، معاينة الأطلس، الأدلة والمشاركة، ثم التعريف والمشاريع بحالاتها والتواصل.
- أعيد بناء الترويسة والتذييل. تنقل مجمع للحاسوب وقائمة مسطحة للهاتف، مع الصفحة النشطة، الإغلاق بلوحة المفاتيح والنقر خارج القائمة، ورابط تجاوز إلى المحتوى.
- اختُصرت صفحات الأعمال والمجلة والمرصد والأدلة ومقدمات التفاصيل. احتُفظ بالمسارات الحالية، والمشغل، وقارئ PDF، والمقارنة الزمنية، ولوحة الإدارة.
- تحسنت الصور: شعار بأحجام مناسبة، وصور مصغرة وأغلفة عبر Next Image عندما يسمح المصدر، مع إبقاء الروابط الخارجية غير المدعومة قابلة للعرض دون تحسين خادمي.

## الوظائف والمكونات

- `PageIntro` للمقدمات ومسار التصفح، و`SearchForm` و`Pagination`، وتحسين بطاقات الأعمال والمؤشرات والأعداد والأدلة وحالات الفراغ والخطأ والتحميل.
- `/search`: بحث في العناوين والأوصاف ونصوص التفاصيل العامة للأعمال والأعداد والمؤشرات والشخصيات والشركات والمهنيين والمحافظات والمديريات ومجالات المرصد وصفحات المنصة، مع تصفية حسب النوع وترقيم النتائج. يطابق العربية دون تشكيل ومع اختلافات الهمزات والأرقام. لا يبحث داخل نص PDF، ولا يفهرس بيانات الاتصال أو المسودات. تظهر الملفات التوضيحية العامة مع وسمها.
- `/contribute`: مساهمات واقتراحات وتصحيحات وطلبات إضافة إلى الأدلة، باستخدام جدول الرسائل وواجهة API الحالية. لا تنشر المساهمة تلقائياً.
- تحقق من المدخلات وحجم الطلب والأصل، ومصيدة للبوتات، وحد إرسال محلي لكل عملية خادم عند توفر عنوان IP، مع دعم Turnstile وإصلاح تهيئته عند إعادة فتح النموذج. الحد المحلي ليس بديلاً عن حماية موزعة على منصة الاستضافة.
- فلاتر عربية وأعداد نتائج وإعادة ضبط وترقيم في المكتبات والأدلة. تصنيفات الأعمال والأدلة مشتقة من المحتوى المتاح.
- تحميل الخريطة عند الحاجة، وحالة إعادة محاولة عند فشل تحميل الحدود، ودعم اختيار المناطق بلوحة المفاتيح. استمرت آليات السحب واللمس والتكبير والحدود الأصلية.
- قالب الشخصيات يدعم المحطات المتاحة من الميلاد والوفاة والمراجع إن وجدت، ويتيح الانتقال إلى المحافظة على الخريطة. لا تُختلق مراجع أو أحداث مفقودة.
- أضيفت Canonical URLs للأقسام والتفاصيل، ومسارات الأعمال إلى Sitemap، واستُبعدت العينات من الفهرسة.

## إصلاحات البيانات

- القراءة على دفعات وبترتيب ثابت تمنع الاقتصار على أول 1000 سجل. أظهر فحص للقراءة فقط وجود **2148 قيمة منشورة**؛ وبالمقارنة مع أول 1000 سجل أصبحت قيم أحدث متاحة لـ **86 مؤشراً**.
- أحدث قيمة تعتمد على سنة القياس والقيمة الصالحة والسلسلة المعتمدة. تُستبعد القيم المفقودة وغير الوطنية وغير المنشورة؛ ويُحتفظ بالصفر. يمنع خلط المصادر دون اعتماد سلسلة.
- فُصل إجمالي المؤشرات المعرّفة والمنشورة عن ذات القيم وعن الخالية، مع بيان انتظار اعتماد المصدر عند التعارض. القيم التقديرية موسومة، والسنوات بلا فواصل آلاف في البطاقات والفلاتر والرسوم والإدارة.
- وُجد ملف مهني منشور واحد يحتوي بريداً تجريبياً محجوزاً. يظهر بحاجة إلى مراجعة، ولا تظهر له شارة التوثيق أو وسائل اتصال مشتبه بها. لم يتغير السجل أو حقل توثيقه في Supabase. تظهر ملاحظة المراجعة للمحررين، ويُمنع توثيق بريد example.com جديد.
- بقي كتالوج الشخصيات الموجود ضمن المشروع، الذي يوسم سجلاته الـ120 صراحة بـ `isDemo`. أصبحت هذه الملفات موسومة كتوضيحية في الدليل والتفاصيل ونتائج البحث، وتُستبعد من فهرسة محركات البحث. عند وجود سجل مقابل في CMS، تكون له الأولوية؛ المسودة تمنع إعادة ظهور النسخة المحلية. يغطي هذا السلوك اختبار مستقل.
- عند الاتصال بقاعدة فعلية، لا تستبدل أخطاء الأدلة أو فراغها بشركات أو مهنيين تجريبيين. المعاينة دون قاعدة بيانات ما زالت موسومة بوضوح.

## التحقق المنفذ

- `npm test`: **9 اختبارات ناجحة** تشمل أحدث سنة، الصفر والفجوات، تعارض المصادر، جلب أكثر من حد الاستجابة، أخطاء الاتصال، البحث العربي، عدم تسريب الاتصال أو المسودات إلى الفهرس، مراجعة البيانات التجريبية، وأولوية CMS على الكتالوج.
- `npm run build`: **ناجح**، بما فيه التجميع وفحص صلاحية الأنواع الذي توفره Next.js. المشروع JavaScript ولا يحتوي أمراً مستقلاً لـ Typecheck.
- `npm run lint`: بلا أخطاء؛ بقيت **9 تحذيرات سابقة** في Hooks لوحة الإدارة والقارئ، وصور المشغل وصفحات PDF المرسومة. انخفض العدد من 13 في الفحص الأولي.
- `node scripts/check-routes.mjs`: **26 فحص HTTP ناجحاً على نسخة الإنتاج المحلية**: الأقسام، البحث وحالة عدم التطابق، المشاركة والإدارة، Sitemap وRobots، وتفاصيل فعلية للأعمال والمجلة والشركة والمهني والشخصية والمؤشر والمجال، مع 404 متوقع ورفض مدخلات النموذج والأصل الخارجي.
- تحققت أيضاً استجابة 401 لواجهة إدارة المحررين دون مصادقة، وصحة ترويسة ومحتوى ملف PDF التجريبي، واستجابة مسار تحسين صورة الشعار، ووجود التسلسل الزمني في صفحة الشخصية.
- لم تُرسل رسائل تجريبية إلى قاعدة الإنتاج، ولم تُعدل سجلات أو صلاحيات أو ملفات فيها، ولم يحصل Push أو نشر.

## حدود التحقق والخطوات قبل النشر

1. **المتصفح:** أظهرت أدوات الجلسة عدم وجود متصفح متصل. أُعدت قواعد تجاوب للهاتف واللوحي والحاسوب، لكن لم يُنفذ فحص مرئي للمقاسات 360 و390 و768 و1024 و1440. يجب مراجعة الالتفاف والتمرير والتركيز وقوائم الهاتف على هذه المقاسات، وتجربة لمس الخريطة وتقليب PDF. لم تُقَس Core Web Vitals أو مطابقة WCAG كاملة.
2. **وظائف الإدارة المصادقة:** لم يُنفذ تسجيل دخول فعلي أو رفع أو نشر أو تعديل صلاحيات. اختبر ذلك بحساب محرر في بيئة اختبار؛ لم تُنشأ بيانات أو حسابات اختبار في الإنتاج.
3. **قراءة الشركات العامة:** كشف فحص anon خطأ سابقاً `42501: permission denied for table editors`؛ القراءة عبر الخادم تعمل. يوجد إصلاح جاهز سابقاً في `supabase/fix-yemeni-products-read-policy.sql`. راجعه وطبقه من Supabase SQL Editor إذا كانت السياسة القديمة ما زالت مستخدمة، ثم اختبر قراءة الشركات المنشورة فقط. لم يُطبّق عن بعد في هذه المهمة.
4. **المهنيون:** راجع الملف الموسوم بالمراجعة، واستبدل معلومات الاتصال التجريبية بعد تأكيد صاحب الملف وموافقته؛ لا يكفي تغيير المظهر لإثبات الهوية.
5. **الشخصيات والمراجع:** لا توجد شخصيات منشورة في جدول Supabase وقت الفحص الأول، والكتالوج الموروث تجريبي ولا يتضمن مراجع تفصيلية لكل ملف. يظهر بوسم واضح في الدليل والبحث، ويُستبعد من فهرسة محركات البحث. راجع السجلات ومراجعها وانشر الملفات المعتمدة من لوحة التحرير. لم تُجر أبحاث تاريخية جديدة أو تُخترع مصادر. يدعم القالب حقول مصادر ومحطات اختيارية إن توفرت؛ لا توجد إضافة جديدة لهذه الحقول في محرر قاعدة البيانات.
6. **النماذج:** مفاتيح Turnstile غير مضبوطة في البيئة الحالية. يمكن تفعيل المتغيرين الموجودين أصلاً، مع حد إرسال على مستوى الاستضافة عند الحاجة. نجاح حفظ رسالة فعلية يحتاج اختباراً في بيئة اختبار.

## قاعدة البيانات والبيئة

لا تغييرات على المخطط أو بيانات الإنتاج أو متغيرات البيئة، ولا اعتماديات جديدة. أنواع المساهمات الجديدة تُحفظ في حقل `messages.type` النصي الموجود. بقيت سياسات الصلاحيات والمصادقة كما هي. استخدم `npm run dev` للمعاينة، وأعد الاختبارات بعد أي إصلاح يدوي للسياسات أو إعدادات النشر.
